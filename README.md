## 🎯 מטרות הפרויקט
1. **מוכנות גבוהה למבחן**: פלטפורמה המדמה את מתכונת המבחן האמריקאי הממשלתי.
2. **למידה פעילה ומבוססת רפלקציה**: משוב מיידי והסבר מנומק (Rationale) על כל שאלה ותשובה.
3. **חיזוק נקודות תורפה**: ניהול אוטומטי של "מאגר טעויות" הנשמר מקומית בדפדפן ומאפשר תרגול ממוקד.
4. **עצמאות טכנולוגית ואפס חיכוך (Zero Setup)**: עבודה מיידית בדפדפן דרך `index.html` ללא התקנת שרת.

## 🚀 מאפייני המערכת

### 1. מנגנון ערבוב רנדומלי כפול (Randomization Engine)
* **סדר השאלות:** מתערבב בכל מבחן וסבב תרגול מחדש (אלגוריתם Fisher-Yates).
* **סדר המסיחים (א', ב', ג', ד'):** **מתערבב רנדומלית בכל הצגה של שאלה**, כך שהלומדת מחויבת להבין את תוכן התשובה ולא להסתמך על מיקומה.

### 2. מצבי למידה ותרגול
* **📝 מצב מבחן (Exam Mode):**
  * בחירת כמות שאלות: 10, 25, 50, 100, או תרגול ממוקד של מאגר הטעויות בלבד.
  * בחירת מקור (מעורבב מכל המאגר או לפי מועד ספציפי) וסינון לפי נושא.
  * סרגל התקדמות, סימון שאלות לעיון חוזר (Flag ★) ורשת ניווט מהירה (Quick Grid).
  * מסך תוצאות והגשה: ציון באחוזים, פירוט מלא של מה שנבחר מול התשובה הנכונה, והסברים פדגוגיים.
  * כפתור מהיר: "תרגל עכשיו רק את השגיאות".
* **💡 מצב למידה ואימון (Study Mode):**
  * הצגת שאלה בודדת בכל פעם.
  * משוב מיידי: בחירת תשובה צובעת אותה מיד בירוק (נכון) או אדום (שגוי) ומציגה את התשובה הנכונה.
  * חשיפת כרטיסיית הסבר פדגוגי עם הפרדה ברורה בין הערת המקור להסבר המורחב.
  * מעבר בלחיצה לשאלה הבאה.
* **🎯 מאגר טעויות חכם (Mistake Bank):**
  * נשמר אוטומטית בדפדפן (`localStorage`).
  * שאלות שגויות מתווספות אוטומטית; מענה נכון עליהן מוציא אותן מהמאגר ומעדכן את המונה בזמן אמת.

### 3. קטגוריות וסטטיסטיקה (Analytics Dashboard)
כל שאלה במאגר מסווגת לאחת מ-**6 קטגוריות הליבה** של הקורס:
1. **תיאוריות למידה ולמידת מבוגרים**: בלום, קולב, אנדרגוגיה של נואלס, עומס קוגניטיבי של סוולר.
2. **מיומנויות פסיכומוטוריות וסימולציה**: שלבי פיטס ופוסנר (קוגניטיבי, אסוציאטיבי, אוטונומי), תרגול, דבריפינג.
3. **משוב, הערכה ורפלקציה**: משוב מעצב ומסכם, מודל פנדלטון, חשיבה רפלקטיבית, הטיות מעריכים (Halo, Leniency).
4. **תפקיד המדריך ויחסי מדריך-סטודנט**: חונכות (Mentoring), מודלי הדרכה, התמודדות עם חרדה, יחסי גומלין.
5. **הסטודנט המתקשה ותוכניות התערבות**: זיהוי סטודנט בסיכון לכישלון, תוכנית תיקון/השלמה (Remediation).
6. **אתיקה, חוק ובטיחות המטופל**: בטיחות המטופל בראש סדר העדיפויות, דילמות אתיות, זכויות החולה.

דשבורד הסטטיסטיקה מציג אחוזי הצלחה לפי כל קטגוריה, מונה שאלות שנענו, ובאנר המלצות חכם המזהה את הנושא החלש ביותר.

## 🧪 בדיקות איכות ואימות (Verification)

המערכת כוללת מערך בדיקות איכות אוטומטיות:
1. **אימות שלמות המאגר (`scripts/verify_database.py`):**
   - ייחודיות מזהי שאלות (`id`).
   - אורך טקסט שאלה תקני.
   - תקינות מסיחים (בדיוק 3 או 4 אפשרויות לא ריקות).
   - תקינות אינדקס תשובה נכונה (`0 <= correctIndex < options.length`).
   - התאמה ל-6 קטגוריות הליבה הרשמיות.
   - קיום הסברים פדגוגיים לכל שאלה.
2. **אימות ערבוב רנדומלי (`scripts/test_shuffle_logic.js`):**
   - הרצת 1,000 סבבי ערבוב רנדומליים המוודאים שהטקסט של התשובה הנכונה נשמר ללא שינוי בכל מצב.

## 💻 הפעלה מהירה

1. פתחו ישירות את הקובץ **`index.html`** בכל דפדפן מודרני (Chrome, Edge, Firefox, Safari).

## 🛠️ ניהול גרסאות, CI/CD ופריסה (Git & GitHub Best Practices)

הפרויקט מנוהל ב-Git לפי הסטנדרטים המובילים בתעשייה:
* **בקרת קבצים קפדנית (`.gitignore`):** סינון סביבות וירטואליות (`.venv/`), קבצי מערכת הפעלה, וקבצי ביניים זמניים.
* **נרמול שורות (`.gitattributes`):** כפיית סיומות שורה אחידות (`LF`) למניעת שיבושי Windows/Linux.
* **ולידציה אוטומטית (GitHub Actions CI):** קובץ `.github/workflows/ci.yml` מריץ אוטומטית אימות שלמות (`verify_database.py`) ובדיקת ערבוב (`test_shuffle_logic.js`) בכל Push ו-Pull Request.
* **פריסה ל-GitHub Pages:**
  1. הגדירו את מאגר ה-GitHub כ-Remote.
  2. בהגדרות המאגר ב-GitHub: `Settings` ➔ `Pages` ➔ תחת `Source` בחרו ב-`Deploy from a branch` (ענף `main`, תיקיית `/root`).
  3. האתר הופך לזמין אונליין מיידית כ-Web App לכל מכשיר!

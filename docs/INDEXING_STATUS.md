## 🐙 תשתית Git ו-CI/CD (גרסה v2.0)
* **איתחול מאגר וענף ראשי:** מאגר מקומי אותחל בענף `main` עם תמיכה מלאה בשמות עבריים (`core.quotepath false`).
* **חוקי סינון (`.gitignore`):** הוגדרו סינונים הרמטיים עבור סביבות פייתון וירטואליות (`.venv/`), קבצי Cache, קבצי ביניים של סריקות OCR (`data/scans/`) וקבצי טיוטה.
* **אחידות שורות (`.gitattributes`):** הגדרת נרמול סיומות שורה (LF) למניעת שיבושים בפלטפורמות מרובות.
* **אינטגרציה רציפה (CI):** נוסף Workflow של GitHub Actions ב-`.github/workflows/ci.yml` המריץ בדיקות אימות אוטומטיות על כל Commit ו-PR.
* **קובץ עצמאי למובייל:** נוצר `simulator_all_in_one.html` (1.1 MB) הכולל את כל השאלות והלוגיקה בקובץ אחד ללא תלויות.
